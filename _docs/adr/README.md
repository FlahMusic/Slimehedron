# Decisions (ADRs)

One short file per decision that is hard to explain from the code alone, or that someone (person or agent) keeps
trying to undo. Format: what we decided, why, what it rules out. A reversed decision is not deleted: it gets
"Superseded by" at the top. `grill-with-docs` and `domain-modeling` read and add to this folder.
Numbering only goes up.
